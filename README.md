## Sobre o Projeto

O **DevAprender C** é um site desenvolvido como parte da disciplina de **Projeto de Aprendizagem Colaborativa Extensionista (PAC)** da **Católica SC**, sob orientação da professora **Tássiana Kautzmann**.

O objetivo principal do projeto é proporcionar um ambiente **gratuito, acessível e interativo** para iniciantes aprenderem **lógica de programação** e a **linguagem C**, promovendo um primeiro contato com conceitos fundamentais de forma prática e didática.
